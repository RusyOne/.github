## What We're Building

Rusy brings traditionally disconnected business systems together under one platform.

Application and network protection built for modern infrastructure.

- Web Application Firewall
- L4–L7 traffic protection
- XDP/eBPF packet filtering
- DDoS mitigation
- Bot detection
- Rate limiting
- Custom security rules
- Origin protection and failover
- DNS and network infrastructure
- Security analytics

## Security

Security is treated as an architectural requirement rather than an add-on.

Projects may incorporate:

- Least-privilege access
- Role-based access control
- Service authentication
- Audit logging
- Network segmentation
- Rate limiting
- Abuse prevention
- Secure secret management
- Defense-in-depth
- Infrastructure monitoring
- Automated security controls

Security issues should be reported privately rather than through public GitHub issues.
